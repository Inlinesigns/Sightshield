# Where SightShield files live

Rule (decided 12 Nov 2026, decision c437334a): every SightShield file is saved in OneDrive under BUSINESS FILES\SightShield. Nothing SightShield-related goes in the Mackenzie & Brown or In Line Signs folders. This GitHub repo stays as Claude's working memory, and everything in it is also copied into the OneDrive folder.

```
BUSINESS FILES\SightShield\
├── 00 Admin\                 plan, roadmap, open items, audits, Claude's working memory
├── 01 Entity and Accounts\   ASIC, ABN, GST, bank, Xero, accountant, insurance, payroll, R&D records
├── 02 Site Access\           Glencore onboarding, prequal, inductions, medicals, MOC and fitment approval
├── 03 Compliance\            SOPs, SWMS, SDS, safety system from On Point Safety, ISO
├── 04 Product and Trial\     film, cleaner, trial protocol, inspections, photos, results
├── 05 Brand\                 logo, colours, template, name and trade mark
└── 06 Commercial\            pricing, quotes, warranty terms, contracts
```

Inside each: `1 Inputs` (what came in), `2 Working` (drafts, safe to ignore), `3 Final` (the current version; if it is in here, it is live). When there are two copies, the oldest goes and the newest stays.
