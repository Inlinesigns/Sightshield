## Working rules from the same chat

- One workstream at a time.
- A fixed weekly block.
- One running list of what is waiting on someone else, so Zac is never blocked twice. That list is `03-open-items.md`.

## Where this roadmap and reality differ

1. **Name.** The roadmap says register under a plain holding-style name and brand later. On 15 Oct the company was ordered as SightShield (one word, then two words as the fallback). If ASIC rejects both, the holding-name route is still available.
2. **Order.** Stage 1 started before Stage 0 finished. The entity is moving; the site requirements are not. Stage 0 is now the thing to chase.
3. **Numbering.** The earlier Stage 0 doc uses stages 0 to 4, with pricing as Stage 4. This roadmap splits build-out and handover into a Stage 5. The repo uses this six-stage version from now on.
4. **Insurance minimum.** "PL is usually $20M on mine sites" is a general assumption, not the site's figure. It stays unconfirmed until Stage 0 is answered.
